# Screen Answer
Кружок поверх всех приложений: тап → скриншот экрана → нейросеть → короткий ответ внизу экрана (тап по ответу закрывает).

## Сборка APK без компьютера
1. Создайте репозиторий на GitHub и загрузите содержимое этой папки (вместе с .github).
2. Вкладка Actions → Build APK → Run workflow (или просто push).
3. Скачайте артефакт ScreenAnswer-debug → app-debug.apk и установите.

Или в Android Studio: Open → Run.
